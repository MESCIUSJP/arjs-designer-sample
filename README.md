# ActiveReportsJS レポートデザイナー

ActiveReportsJS 6.0.1 を使った、ブラウザー上でレポートを作成・編集するサンプルアプリです。レポート定義はこのアプリを実行しているサーバーの `Reports` フォルダーに保存します。ActiveReportsJS のライブラリと日本語ロケールは MESCIUS CDN から読み込みます。

## 起動方法

1. Node.js をインストールします。
2. ターミナルでこのプロジェクトのフォルダーに移動します。
3. 次のコマンドでローカルサーバーを起動します。

```shell
node server.js
```

4. ブラウザーで <http://127.0.0.1:3000> を開きます。

サーバーを停止するには、ターミナルで `Ctrl+C` を押します。ActiveReportsJS 本体と日本語ロケールは MESCIUS CDN から取得するため、アプリの利用中はインターネット接続が必要です。

### 接続先の変更

既定では `127.0.0.1:3000` で待ち受けます。必要な場合は環境変数で変更できます。

- `HOST`: サーバーが待ち受けるIPアドレス（既定値: `127.0.0.1`）
- `PORT`: サーバーのポート番号（既定値: `3000`）
- `ORIGIN`: ブラウザーに案内するオリジンURL。未指定の場合は `HOST` と `PORT` から生成します。

## ライセンスキー

ローカルで開発ライセンスを利用する場合は、次の手順で設定します。

1. プロジェクト直下の `license.example.js` をコピーします。
2. コピーしたファイルを同じ場所に `license.js` という名前で保存します。
3. `license.js` の `window.ARJS_DISTRIBUTION_KEY` に、MESCIUS から取得したライセンスキーを設定します。
4. ブラウザーを再読み込みします。

このサンプルは ActiveReportsJS のライブラリ読み込み後に `/license.js` を読み込み、キーが設定されていればライブラリに登録します。ローカル実行時は開発ライセンスキーを設定すると開発ライセンスで動作します。キーを設定しない場合はトライアル版として動作します。

`license.js` は `.gitignore` に登録されており、Git の管理対象になりません。実際のライセンスキーを `license.example.js` やその他の公開ファイルに記載しないでください。`license.example.js` は設定方法を示すサンプルであり、実際のキーは含みません。

## レポートの作成とファイル操作

デザイナーのツールバーから、新規作成・開く・保存・名前を付けて保存・プレビューを利用できます。新規作成画面では **ページレポート** と **RDLレポート** を選べます。

- **ページレポート**: `Reports/template/pagereports-template.rdlx-json` を読み込み、ページレポートの初期状態を作ります。ページレポートは初期設定を含むテンプレートを用意しています。
- **RDLレポート**: 新しい空のレポート定義から作成します。
- **保存形式**: どちらの形式も `.rdlx-json` で保存します。形式はファイル名ではなく、レポート定義の内容から判定します。
- **保存**: 開いているファイルがある場合はそのファイルを上書きします。まだ保存していないレポートの場合は、名前を入力して保存します。
- **名前を付けて保存**: ファイル名を入力して保存します。同じ名前のファイルがすでにある場合は、上書きするか確認します。
- **開く**: `Reports` フォルダー直下のレポート一覧からファイルを選びます。

ファイル名には空欄、パス、使用できない文字、Windows の予約名などを指定できません。保存・読込 API が扱うのは `Reports` 直下の `.rdlx-json` ファイルだけです。サーバー側でもファイル名と保存先を検証し、`Reports` フォルダー外へのアクセスを防ぎます。`Reports/Parts` と `Reports/template` は、通常のレポート保存先・一覧には含まれません。

## フォルダー構成

```text
.
├── server.js                         # WebアプリとレポートAPIを配信するNode.jsサーバー
├── index.html                        # デザイナー画面とダイアログ
├── main.js                           # 新規作成、ファイル操作、パーツライブラリの登録
├── style.css                         # アプリ独自の見た目
├── license.example.js                # ライセンス設定のサンプル
└── Reports/
    ├── *.rdlx-json                   # 保存したレポート（Reports直下）
    ├── Parts/                        # デザイナーに登録するレポートパーツライブラリ
    │   ├── BsParts.rdlx-json
    │   └── InvoiceParts.rdlx-json
    └── template/
        └── pagereports-template.rdlx-json # 新しいページレポートのひな形
```

## レポートパーツライブラリ

### レポートパーツとは

レポートパーツは、レポートの中で繰り返し使うレイアウトや項目を、再利用できる部品としてまとめたものです。たとえば、会社情報、請求書の明細表、決まった見出しや書式を部品にしておくと、別のレポートを作るときにも同じデザインを利用できます。毎回同じ配置や書式を作り直さずに済み、複数のレポートで見た目をそろえやすくなります。

### このサンプルでの登録内容

部品の定義は `Reports/Parts` フォルダーにあります。

- `BsParts.rdlx-json`: BS（貸借対照表）向けのレポートパーツライブラリです。
- `InvoiceParts.rdlx-json`: 請求書向けのレポートパーツライブラリです。

`main.js` では `designer.setReportPartsLibraries` を呼び出し、この2つのファイルをデザイナーに登録しています。ライブラリごとに、ファイルのURL（`id`）、内部で識別する名前（`name`）、デザイナー上に表示する名前（`displayName`）を指定します。登録されたライブラリのパーツは、デザイナー上で選んで編集中のレポートへ追加できます。

**重要:** ライブラリファイルを `Reports/Parts` に置くだけではデザイナーには表示されません。`main.js` の `setReportPartsLibraries` に登録する必要があります。また、ここに置いたライブラリは通常の「開く」一覧や保存対象とは別のものです。部品ライブラリを使う場合も、完成したレポートは通常どおり `Reports` 直下に保存します。

### ライブラリを追加・変更するとき

1. ActiveReportsJS のレポートアイテムライブラリの手順に沿ってライブラリを作成します。
2. 作成した `.rdlx-json` ファイルを `Reports/Parts` に配置します。
3. `main.js` の `designer.setReportPartsLibraries` にファイルのURLと表示名を追加します。
4. アプリを再読み込みし、デザイナーから追加したパーツを選べることを確認します。
